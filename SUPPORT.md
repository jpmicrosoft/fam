# Support

FAM is independently maintained and does not provide a commercial support or
response-time commitment.

## Where to ask

- **Reproducible defect:** use the GitHub bug report form.
- **Feature or workflow proposal:** use the feature request form.
- **Usage question:** check the [README](README.md), [FAQ](docs/faq.md), and
  [command reference](docs/command-reference.md) before opening an issue.
- **Security vulnerability:** follow [SECURITY.md](SECURITY.md). Never disclose
  a suspected vulnerability in a public issue.
- **Conduct concern:** follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Include the FAM version, operating system, relevant command, expected behavior,
actual behavior, and sanitized reproduction material. Remove credentials, real
tenant or subscription identifiers, customer information, and private
endpoints before posting.

Azure service availability, billing, quota approval, and platform incidents
remain Microsoft Azure support concerns rather than FAM defects.
